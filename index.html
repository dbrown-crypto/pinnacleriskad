What We Need to Quote You

Trucking Insurance Quote Checklist

  • Driver licenses for all drivers and owners
  • VINs for all vehicles
  • Current policy or declarations page if available
  • DOT and MC number if applicable
  • Type of freight hauled
  • Radius of travel
  • Loss runs if available

  • Property address
  • Year built
  • Square footage
  • Current policy or declarations page if available
  • Occupancy status
  • Rental income
  • Any prior losses
  • Desired effective date
